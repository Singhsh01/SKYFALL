# Real terrain data

Generated by `tools/fetch_real_terrain.py` from AWS Terrain Tiles (Mapzen terrarium encoding),
open data derived from SRTM, GMTED2010, ETOPO1, NED, Copernicus and other sources.
Attribution: https://github.com/tilezen/joerd/blob/master/docs/attribution.md

Each `.skt` file: 32 x 32 km, 1025 x 1025 samples, int16 metres (format in src/sim/Locations.hpp).
